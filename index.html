Moteur de Prédiction de Churn Télécom

Donner aux machines une capacité d'intuition prédictive sur le comportement d'abandon des abonnés télécom via des arbres de décision, le rééquilibrage de classes et la sérialisation de modèles.

La Machine Prédictive

Les opérateurs télécom perdent des sommes importantes lors des départs imprévus d'abonnés. Ce pipeline de Machine Learning ingère la durée d'engagement, les tickets d'assistance et la consommation de données pour prédire le départ du client avant qu'il ne se produise.

Algorithme du Modèle : DecisionTreeClassifier (Scikit-Learn)
Équilibrage des Classes : SMOTE (Synthetic Minority Over-sampling)
Pipeline d'Encodage : OneHotEncoder + LabelEncoder
Sérialisation : Export Modèle Joblib

STRATE 04 // THE BATTLEFIELD (CRISES DU MONDE RÉEL)

Bugs, Erreurs & Crises Résolues

Les grands ingénieurs ne se reconnaissent pas à un code sans bug du premier coup, mais à leur vitesse méthodique à diagnostiquer et corriger des architectures en panne.

[ CRISE #01 ] FUITE D'AUTH SANCTUM MULTI-TENANT

Problème : Les cookies de session fuitaient entre différents sous-domaines universitaires lors de l'authentification.

Solution : Configuration dynamique du domaine de session dans Laravel + liste blanche stricte des origines CORS par sous-domaine tenant.
[ CRISE #02 ] PERTE SONORE NAT SIP ASTERISK

Problème : Audio à sens unique lors des appels WebRTC & SIP à travers des pare-feux et routeurs distants.

Solution : Implémentation de relais TURN/STUN avec liaison explicite externip et localnet dans rtp.conf sous Asterisk.
[ CRISE #03 ] PIÈGE DE SMOTE EN MACHINE LEARNING

Problème : Modèle affichant 99% de précision artificielle car le dataset contenait 95% de non-churners.

Solution : Bascule de l'évaluation vers le F1-Score & ROC-AUC avec sur-échantillonnage des classes minoritaires par SMOTE.
[ CRISE #04 ] PLANTAGE ROUTE:CACHE MULTI-TENANT

Problème : L'exécution de route:cache sous Laravel cassait les règles de routage dynamique par sous-domaine.

Solution : Intégration de résolveurs de closures Stancl Tenancy pour séparer les routes statiques du binding dynamique de domaine.
